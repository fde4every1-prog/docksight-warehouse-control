# Baseline KPI candidates

- order cycle time
- on-time carrier departure
- pick/pack exception rate
- inventory accuracy
- robot productive utilization
- robot deadlock rate
- charging queue time
- travel distance per completed task
- congestion minutes
- maintenance-induced downtime
- safety event rate
- false availability rate
- recovery time after control-system outage
- manual overrides per 1,000 tasks
- cost per fulfilled order
- human interventions per 1,000 robot tasks

Participants should compute baselines rather than trust undocumented management numbers.
