# Target capabilities (not mandated technologies)

A successful intervention should improve: canonical identity, physical/digital reconciliation, end-to-end observability, global task prioritization, constraint-aware planning, congestion and cutoff risk forecasting, resilience/replanning, evidence-backed decisions, bounded autonomy, safety assurance, evals/TEVV, and measurable value.

Possible interventions may include conventional services, rules, event architecture, optimization, ontology/KG, digital twin, predictive models, RAG, or agents. None are mandatory by default.
